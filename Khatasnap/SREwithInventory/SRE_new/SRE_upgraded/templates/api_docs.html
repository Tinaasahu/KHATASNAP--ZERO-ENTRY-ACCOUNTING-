POST /api/ocr1 📄 Sales Bill → Deduct Stock
FieldTypeRequiredDescription
transaction_idstringoptionalUnique ID — auto-generated if not provided
itemsarrayrequiredList of items from bill
items[].namestringrequiredProduct name (fuzzy matched)
items[].qtyintrequiredQuantity to deduct
Example Request
{ "transaction_id": "OCR1-20240310-001", "items": [ { "name": "Parle-G Biscuit", "qty": 5 }, { "name": "Maggi Noodles", "qty": 3 } ] }
Example Response
{ "success": true, "txn_id": "OCR1-20240310-001", "log": [ { "status": "deducted", "name": "Parle-G Biscuit", "qty": 5, "confidence": 1.0 }, { "status": "deducted", "name": "Maggi Noodles", "qty": 3, "confidence": 0.85 } ] }
POST /api/ocr2 📦 Distributor Bill → Add Stock
FieldTypeRequiredDescription
transaction_idstringoptionalUnique ID — auto-generated if not provided
itemsarrayrequiredList of items from distributor bill
items[].namestringrequiredProduct name — new product auto-created if not found
items[].qtyintrequiredQuantity to add
Example Request
{ "transaction_id": "OCR2-20240310-001", "items": [ { "name": "Parle-G Biscuit", "qty": 100 }, { "name": "Maggi Noodles", "qty": 50 }, { "name": "New Product XYZ", "qty": 25 } ] }
Response status values
added — stock increased created — new product made error — something failed

POST /api/calculator 🧮 Calculator Predictions → Smart Deduct
FieldTypeRequiredDescription
transaction_idstringoptionalUnique ID
bill_totalfloatoptionalTotal bill amount
items[].namestringrequiredPredicted product name
items[].qtyintrequiredPredicted quantity
items[].pricefloatoptionalPredicted price
items[].confidencefloatrequired0.0 to 1.0 confidence score
Confidence Rules:
≥ 0.75 → Auto deduct immediately
0.50 – 0.74 → Deduct + flagged as uncertain (SRE review)
< 0.50 → Skipped entirely
Example Request
{ "transaction_id": "CALC-20240310-001", "bill_total": 150.00, "items": [ { "name": "Parle-G", "qty": 3, "price": 10.0, "confidence": 0.95 }, { "name": "Maggi", "qty": 2, "price": 14.0, "confidence": 0.62 }, { "name": "???", "qty": 1, "price": 5.0, "confidence": 0.30 } ] }

FieldTypeRequiredDescription

corrections[].correct_qtyintrequiredThe correct physical stock count
corrections[].reasonstringoptionalReason for correction

{ "corrections": [ { "product_id": 1, "correct_qty": 45, "reason": "physical count" }, { "product_id": 2, "correct_qty": 12, "reason": "damaged goods removed" } ] }
